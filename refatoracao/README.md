# Índice — pasta `refatoracao/`

Códigos do Tobias antigo **copiados** (o original em `programasPC/tobias` permanece intacto) para avaliação futura: refatorar, reintroduzir ou remover.

Não importar estes arquivos no app ativo. O app em `src/` é a nova versão enxuta.

## Pastas

| Pasta | Conteúdo |
|-------|----------|
| `servicos/` | Regras de negócio do RPG de hábitos (quests, metas, XP flow, loja…) |
| `telas/` | Páginas App Router fora da nova visão |
| `componentes/` | UI de log livre, calendário de humor, HUD de streak… |
| `helpers/` | Cálculo de atributos e títulos |
| `cron/` | Jobs de quests diárias e scrape de frases |
| `scripts/` | CLI de scrape |
| `schema/` | Migration Postgres legada + aviso da API Express |
